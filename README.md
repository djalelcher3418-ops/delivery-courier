# Delivery — تطبيق الموصّل (Flutter)

نفس قاعدة بيانات Firebase التي يستعملها الموقع delivery-dz.pages.dev وتطبيق الزبون.
كل رفع للكود على GitHub يبني ملف APK تلقائياً ويضعه في صفحة **Releases** باسم `Courier-N.apk`.

- الدخول برقم الهاتف وكلمة السر (نفس حساب الموصّل في الموقع).
- عروض التوصيل تصل للأقرب مع صوت وعدّ تنازلي 60 ثانية: قبول أو رفض.
- طلبات «اشترِ لي» المفتوحة، صفحة التوصيلة (المحل ← الزبون)، الاتصال، الطريق في الخرائط، الدردشة.
- حصيلتي: الربح اليوم، المال الذي معك ولمن تسلّمه، والحد المسموح.
- عند التشغيل يبقى الموقع والطلبات شغالين والشاشة مطفأة (إشعار ثابت «أنت متصل»).
- السجل: ربح آخر 7 أيام في أعمدة، وكل توصيلات آخر 30 يوماً مجمّعة حسب اليوم مع التقييم وحالة التسوية.
- حسابي: التقييم، فحص GPS وإذن الموقع، تجربة صوت التنبيه، ونصائح لتبقى الطلبات تصل والشاشة مطفأة.
- تنبيه بصوت إذا أُلغي طلب تعمل عليه، وإشعار عندما يسجّل الزبون الاستلام بنفسه.
- إشعار في الهاتف للعرض الجديد يضيء الشاشة ويظهر فوق القفل، مع رنين يتكرر حتى ترد، وإشعارات لرسائل الزبون وإلغاء الطلبات.
